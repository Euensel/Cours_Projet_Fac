BUSY Bar est un dispositif multi-outil de productivité avec un écran LED pixelisé. Minuteur de concentration avec fonction de blocage des distractions sur votre téléphone et PC. Entièrement personnalisable, open-source et pret pour la maison connectée

Outil de productivité

Blocage des distractions, message BUSY personnalisé, minuteur de concentration, synchronisation multiplateforme

Application et intégration

Bibliothèque d'application connexion à des logiciels tiers, intégration avec les événements de calendrier et les apples

Support maison connectée

Connectez-vous à Googlz Home et Apple Home via le protocole Master

Pour les développeurs

API HTTP ouverte, SDK open-source, bibliothèque Python/Go/JavaScript sans verroullage fournisseur

Montrez que vous etes occupé

Empechez les autres d'iterrompre votre concentration profonde. L'écran affiche que vous etes occupé et quand vous serez à nouveau disponible.

Activation instantanée

Actvez et désactivez le statut BUSY manuellement avec un large bouton. Fonctionne entièrement hors ligne, sans logiciel supplémentaire requis

Set timer

Set an optional expiration timer BUSY using the scroll wheel t o let others know when you'll be available again
